BIG SKILLS FOR LITTLE ONES — PWA App (by AFSR)
================================================

This folder is the complete, installable web app (PWA).
All 75 skills, all illustrations, offline support, and the certificate are included.

HOW TO HOST (choose one):

OPTION A — Netlify (easiest for multi-file apps):
  1. Go to app.netlify.com  →  "Add new site"  →  "Deploy manually"
  2. Drag this ENTIRE folder onto the upload area
  3. Done — you get a live URL instantly

OPTION B — GitHub Pages:
  1. Create a repo (e.g. big-skills-app)
  2. Upload ALL files AND the images/ folder (keep the structure)
  3. Settings → Pages → Branch: main / root → Save
  4. Open https://YOUR-USERNAME.github.io/big-skills-app/

IMPORTANT: keep the folder structure intact —
  index.html, skills.js, sw.js, manifest.json, privacy.html
  images/  (all the pictures live here)

FILES:
  index.html      the app
  skills.js       all 75 skills' text
  images/         82 illustrations + section images + certificate + app icons
  manifest.json   makes it installable ("Add to Home Screen")
  sw.js           offline support (service worker)
  privacy.html    Privacy Policy & FAQ (linked from the app)

PRIVACY: collects no data. Everything stays on the device.
